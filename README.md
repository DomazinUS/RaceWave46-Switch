# RaceWave46 for Nintendo Switch

RaceWave46 is an unofficial Wave Race 64 recompilation for Nintendo Switch, celebrating its 30th anniversary. Features Deko3D/OpenGL renderers, 60FPS at 720p portable/1080p docked at stock clocks, enhanced local two-player mode, MSAA, texture packs, RetroAchievements, Dolphin ghost in Time Trail mode, rumble and optional water/sky reflections and shadows. Requires your own ROM.
